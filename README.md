# 🤖 Friday – Desktop Assistant

Friday is a Python-based desktop voice assistant inspired by Jarvis.
It can open applications, search Wikipedia, play music, tell time,
open websites, and send emails using voice commands.

## 🚀 Features
- Voice recognition
- Text-to-speech response
- Wikipedia search
- Open apps & websites
- Play music
- Send emails
- Tell the current time
- There are two voices, male/female

## 🛠 Tech Stack
- Python
- pyttsx3
- SpeechRecognition
- Wikipedia API
- SMTP
- pip date

## ▶️ How to Run
```bash
pip install pyttsx3 SpeechRecognition wikipedia
python Friday.py
